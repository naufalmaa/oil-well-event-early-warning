## Reproduce

```bash
git clone https://github.com/naufalmaa/oil-well-event-early-warning.git
cd oil-well-event-early-warning
make setup      # uv sync + pre-commit
make data       # download + checksum
make baseline   # stage 5
make train      # stage 6
make evaluate   # stage 7 → reports/metrics.json, reports/figures/
```

Tested on Ubuntu (WSL2) with Python 3.12 and [uv](https://docs.astral.sh/uv/).
