# 0001 · Record decisions as short ADRs

- **Status:** accepted
- **Context:** Each lifecycle loop (error analysis → new feature/split/threshold) changes the project. Without a record, the README can't explain *why*.
- **Decision:** One file per decision: `NNNN-title.md` with Status, Context, Decision, Consequences. Five to fifteen lines each.
- **Consequences:** The "Decisions & lessons" section of the README links here; interview stories come from here.
